# Orchetta overview

1. Call `list_organizations`. If there is more than one workspace, ask which one.
2. Call `organization_overview` and `list_journeys` for it.
3. Reply in a short list: each journey with its stage count and the number of needs and pain points on it, then the workspace's record kinds and how many of each.
4. End by offering to open one journey stage by stage with `get_journey`.
